# civita-benchmarking

Part of CIVITA, the Computational Infrastructure for Validation, Integration, Testing, and Assessment.

Scientific tools and workflows for standardized computational benchmarking.

This component is under development. The planned workflows will support comparisons across versions of computational frameworks, implementations of the same model, and different computational models.
